# A Mystica — site e painel

Loja online da A Mystica (amystica.com.br).

- `public/` — arquivos do site (index.html, ícones, cabeçalhos de segurança)
- `wrangler.jsonc` — configuração do Cloudflare Workers

Cada atualização enviada para a branch `main` é publicada automaticamente pelo Cloudflare.
Banco de dados e login: Supabase.
